# Comment Node
## Instructions for data entry
Currently, the Comment node can only be used for Synonyms, although we hope to add this feature to other node types in the future. The purpose of this node is to provide feedback on proposed Synonyms.

## REQUIRED FIELDS
**Synonym** – Choose the Synonym node that you would like to write a Comment about.

**Comment** – Write out the text of your comment. Include the date at the end of the text. There is no need to include your name, as it will be automatically displayed with the Comment.

**Parent Comment**  – If you are replying to an existing comment, choose that comment from this list. If you would like to start a new comment thread on the Synonym, then leave this field blank.

## OPTIONAL FIELDS
**Reference** – Select one or more References that support your Comment, if applicable. Only include published References, and these must already exist in PBot. Multiple References can be associated with a Comment by clicking “ADD REFERENCE”. Enter the order number for the Reference to indicate its priority in the reference list, with the most relevant publication as order 1.
