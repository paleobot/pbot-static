# Character Node
## Instructions for data entry
PBot Schemas are hierarchical structures with lower-ranks being dependent on higher-ranks. Therefore, each rank must be added to a Schema in order from the highest position in the hierarchy to the lowest position in the hierarchy. 
* PBot instills a hierarchical organization to schemas by allowing users to create Character parent-child relationship between characters; this allows for parent Characters to act as categorical headers as a means to group sets of related characters. The lowest rank Character is the one that should have alternative States.
* PBot allows for up to 5 levels of hierarchical characters (thus up to 4 Heading Characters and then the actual Characters with States). Thus, the Character ranks available in PBot include organizational header, organizational subheader, organizational subsubheader, organizational subsusbsubheader, and character. Although Character is listed as the lowest ranked, it can be dependent on any rank of organizational header. A parent character simply refers to the next higher rank in the hierarchy. 

## REQUIRED FIELDS: 
**Schema** –  Select a schema from the dropdown menu to add a Character. 

**Parent Character** – If applicable, select the higher-ranked organizational header Character that the new Character belongs to. Skip this step if you are entering a top-rank organizational header (and thus not a sub-header). Also skip this step for cases where a character is not dependent on any rank of organizational header. Note that as you add more Characters to a schema, the drop-down menu for Parent Character will reflect the hierarchical organization that has been generated by use of bold font for top-level Characters and then indented sub-headings and Characters.

**Name** – Enter organizational header names using title case. Enter character names using sentence case. These names should be precise and informative, but concise, as they will appear in the selection drop-down menus when applying a schema to score specimens.

## OPTIONAL FIELDS:
**Definition** – Enter a brief definition using sentence case. Include citation(s) if appropriate. 

**Order** – This function allows schema developers to control where character names appear in lists for users. Enter a number to indicate the position of each character for listing purposes. Order is specific to each rank of organizational header and each character rank group (see example below).
